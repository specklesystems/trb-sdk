02 / EXTRACTED DATA

Geometry, properties
and model structure.

Use the reader for file conversion, property extraction and model analysis. Decode the geometry you need and pass the results to your own viewer, database or processing pipeline.

01

Geometry and materials

Read triangle meshes, triangulate boundary representations and tessellate supported reinforcement sweeps. Get positions, normals, UVs and indices, together with instance placements, layers and surface materials.

MESHES · PLACEMENTS · MATERIALS
02

Object properties

Resolve typed property values and property sets for each entity. Read object classes and identifiers, including GUIDs and IFC GlobalIds. Export resolved properties as CSV for spreadsheets or further analysis.

IDENTITIES · CLASSES · PROPERTIES
03

Hierarchy and instances

Read parent–child relationships and connect geometry instances to their entities. Shared geometry definitions remain separate from placements, so applications can preserve instancing.

ENTITIES · HIERARCHY · INSTANCING

03 / USING THE SDK

Read a file.
Work with its contents.

Build the TypeScript package from source, then use the command-line tools or import the reader into your application.

STEP 01

Build the reader

You’ll need Node.js 18 or newer and npm. The SDK has no runtime dependencies.

Source and documentation ↗
Terminal 
git clone https://github.com/specklesystems/trb-sdk.git
cd trb-sdk
npm ci
npm run build
STEP 02

Inspect or export a model

Point the tools at a local .trb file. Inspect its contents, export properties to CSV, or create a USDZ file with instanced geometry and materials.

Command-line tools ↗
Terminal 
node dist/inspect.js model.trb

node dist/export-csv.js model.trb properties.csv
node dist/export-usdz.js model.trb model.usdz
Exporters process supported geometry. See the support matrix for current coverage.
READER API

Decode what you need

Open an ArrayBuffer or Uint8Array, then read entities, properties and geometry on demand. The same reader works in Node.js and the browser.

API examples ↗
JavaScript · in the cloned repository 
import { readFileSync } from 'node:fs';
import { TrimBimReader } from './dist/index.js';

const model = TrimBimReader.open(
  readFileSync('model.trb'), { strict: true }
);
const properties = model.propertiesByEntity();

for (const instance of model.allInstances()) {
  const geometry = model.decode(instance);
  if (geometry.kind === 'triangles') {
    console.log(instance.entityIndex,
      geometry.positions, geometry.indices,
      properties.get(instance.entityIndex));
  }
}

04 / FORMAT SUPPORT

Supported formats
and limitations.

The reader is validated against TrimBIM files from IFC, SketchUp, Navisworks and Tekla writers. Coverage depends on the geometry types stored in the file.

Read the full support matrix ↗
File format
TrimBIM (.trb), validated against TRB8
Runtime
Node.js 18+ and modern browsers. Export commands run in Node.js.
Distribution
TypeScript source, compiled JavaScript and type declarations
Licence
GNU AGPL v3.0 ↗
Compatibility
TrimBIM has no published compatibility guarantee. Strict mode rejects versions other than TRB8; unsupported geometry types are reported by the decoder.

Alignment curves, grid lines, graphics containers and bolts are available through low-level accessors. Texture bytes and georeferencing are also low-level; these are not yet exposed by the high-level reader API.
